LX 音乐 iOS 客户端

基于 lxserver（LX Music Sync Server）的原生 SwiftUI 客户端 · 界面参考汽水音乐

App 分层架构

视图层 Views（SwiftUI）
RootView(Tab) · 推荐/歌单/我的 · 搜索 · 全屏播放器 · 迷你播放条 · 缓存/设置/备份
状态层 Stores / Player
AppSession（连接/登录/外观） · PlayerManager（AVPlayer 队列/歌词/倍速/音质） · ServerConfig 持久化
网络层 Networking · LXAPIClient
REST API 全接口封装（JSON + x-user-token + 播放器会话 Cookie）· 容错解码多平台返回
数据模型 Models
Song · SongList · Artist · Album · Cache · UserList · LyricLine · Comment
服务端 lxserver（Express + WebSocket）
聚合搜索 · 歌单/榜单 · 播放直链 · 歌词/评论 · 缓存 · 用户同步 · WebDAV · Subsonic

关键设计决策

认证双通道播放器密码（Cookie 会话）+ 用户账号（x-user-token），游客可浏览、登录后可同步。
容错解码多平台返回结构不一致，模型层多路径提取歌曲/封面/列表，稳定兼容。
ATS 放行允许 http，适配局域网内网 lxserver 部署与 http 音频流。
后台播放AVAudioSession .playback + 锁屏远程控制 + NowPlaying 信息。
CI 产 IPAGitHub Actions 在 macOS runner 编译打包 .ipa，TrollStore 可直接安装。
